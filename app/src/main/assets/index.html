🌐 Übersetzung App

Polnisch · Englisch · Deutsch – offline und online
Ganze Sätze aus dem Sprachführer werden genau übersetzt. Andere Texte werden Wort für Wort aus dem eingebauten Wörterbuch übersetzt – das ist eine Hilfe, keine perfekte Grammatik. Unbekannte Wörter erscheinen grau.

🎧 Gesprächsmodus

Tippe auf einen Knopf und sprich.
Hier erscheint euer Gespräch – Original und Übersetzung.
Tippe auf eine Nachricht, um sie groß anzuzeigen.

⚙️ Einstellungen

So funktioniert's mit Kopfhörer: Du hörst die deutsche Übersetzung im Ohr, dein Gegenüber hört deine Antwort auf Polnisch aus dem Handy-Lautsprecher. Das Handy-Mikrofon nimmt beide auf – halte es zwischen euch.

Ohne Internet: Die Spracherkennung braucht dafür die Offline-Sprachpakete für Polnisch, Englisch und Deutsch: Google-App öffnen → Profilbild → Einstellungen → Sprache & Sprache­eingabe (bzw. „Offline-Spracherkennung“) → die gewünschten Sprachen herunterladen. Die Übersetzung braucht das Übersetzungs-Paket (siehe „Übersetzen“).

ℹ️ So bleibt alles offline

    
Diese Datei enthält alles in sich – keine Internetverbindung nötig. Speichere sie auf dem Handy (z. B. Ordner „Downloads“) und öffne sie im Browser. Tipp: Im Chrome-Menü „Zum Startbildschirm hinzufügen“, dann hast du ein App-Symbol.

Vorlesen nutzt die Sprachausgabe deines Handys. Damit Polnisch auch offline vorgelesen wird: Android-Einstellungen → System → Sprachen → Sprachausgabe → Google-Sprachausgabe → Sprachdaten installieren → Polnisch herunterladen.
